
# Thermodynamic Analysis

This folder contains the complete preliminary thermodynamic analysis of the Turbofan Engine V1.

Contents:

- GNU Octave source code
- Numerical outputs
- Input datasets
- Performance summaries
- Future analysis plots

The analysis follows the engine flow sequence:

1. Atmospheric Conditions
2. High-Pressure Compressor
3. Combustion Chamber
4. High-Pressure Turbine
5. Low-Pressure Turbine
6. Core Exhaust Nozzle
7. Bypass Exhaust Nozzle
8. Net Thrust
9. Thrust Specific Fuel Consumption

Software:
- GNU Octave
