# RAI Turbofan Engine V1

## Conceptual Design and Thermodynamic Analysis of a Two-Spool High-Bypass Turbofan Engine

---

## Project Overview

This repository presents the conceptual design, CAD development, and preliminary thermodynamic analysis of a two-spool high-bypass turbofan engine developed as an independent aerospace engineering project.

The project integrates mechanical design, propulsion fundamentals, numerical analysis, and engineering documentation into a single portfolio project.

---

## Objectives

- Design a conceptual turbofan engine using Autodesk Fusion 360
- Perform preliminary thermodynamic cycle analysis
- Evaluate engine performance using GNU Octave
- Develop professional engineering documentation
- Build a foundation for future aerospace propulsion projects

## Engine Specifications

| Parameter | Value |
|------------|-------|
| Engine Type | Two-Spool High-Bypass Turbofan |
| Bypass Ratio | 5.0 |
| Total Air Mass Flow | 120 kg/s |
| Core Air Mass Flow | 20 kg/s |
| Bypass Air Mass Flow | 100 kg/s |
| Net Thrust | 36.41 kN |
| Fuel Mass Flow | 0.329 kg/s |
| TSFC | 32.53 kg/(kN·h) |
